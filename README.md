- I've solved **1000+ problems** across LeetCode and Codeforces.

## Work at Paytm

- Built an **MCP server** with 11+ API tools, OAuth 2.0 and Grafana dashboards, letting 6,000+ merchants run payment operations through Claude and OpenAI.
- Replaced polling in UPI PSP flows with **Redis Pub/Sub**: about 90% fewer Redis reads, and notification latency dropped from 250 ms to under 10 ms.
- Built the Paytm Payments node for **n8n** (13 modules) for 50,000+ self-hosted instances.
- Moved hardcoded credentials to **HashiCorp Vault**, fixing 3+ production vulnerabilities.
- Designed an AI agent orchestrator on **Kafka**.
